# 作曲の指針（music-composition-skills が使えない場合の最低限）

## 用途から決める

| 用途 | 目安 |
|---|---|
| 会話・解説の後ろで流すBGM | 中域の持続音と密度を抑え、台詞の帯域（約300Hz〜3kHz）を空ける。旋律は短い動機の反復。8〜16小節ループ |
| まとめ・エンディング | 旋律を前に出し、主題の提示→応答→展開→終止。達成感なら長調・上行、余韻なら IV→V→I を遅らせる |
| アウトロ | 短いフック。次回への期待なら V で終える／穏やかなら I で静かに閉じる |
| ジングル | 指定尺に収める（例：6秒）。最後に明確な終止 |
| 見出し・反応のSE | 1秒前後。上昇＝前向き、下降＝落ち着き、跳躍＝驚き。立ち上がりと終止を明確に |

## 旋律・和声

- 2小節の「問い」と2小節の「答え」で4小節の文を作り、4小節目は伸ばすか主音へ解決して区切る。
- 強拍には現在のコードの構成音を置き、経過音は弱拍に。
- 進行の例：I–vi–IV–V、I–V–vi–IV、ii–V–I、I–IV–I–V、vi–IV–I–V（切なさ）
- ループ曲は最終小節から1小節目へ戻る進行が自然になるよう、最終小節を V や IV にする。

## 候補の作り分け

候補数を増やすときは、次の軸を組み合わせて候補ごとに変える（移調・テンポ違いだけの複製にしない）。

- 拍子：4/4・3/4・6/8・2/4・5/4
- リズム：ボサ・ワルツ・マーチ・シャッフル・ブレイクビーツ・4つ打ち・ドラムなし
- 編成：リードの音色（pulse / flute / bell / piano …）、伴奏（分散和音／刻み／持続）、打楽器の有無
- 旋律の輪郭：上行・下行・山型・同音反復・跳躍

## パート分け

REAPER版では1パート＝1トラックになり、役割ごとに音色が作られる。

- メロディー、応答（対旋律）、和音（Harmony/Pad）、分散和音（Arp）、ベース、Kick・Snare・Hat などを別パートに。
- 同じ音色でも役割が違えば別パートにする。
